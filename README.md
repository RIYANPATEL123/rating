# 🏃 NutriTrack Pro — Smart Fitness & Nutrition Tracker

A full-featured nutrition tracking web application built 
with vanilla HTML, CSS, and JavaScript.

## 🌐 Live Demo
👉 **[nutri-trackpro.netlify.app](https://nutri-trackpro.netlify.app)**

---

## ✨ Features

- 🔐 **Authentication** — Login & signup system
- 🧭 **6-Step Onboarding** — Gender, body stats, health 
  profile, goal setting, BMI calculator, nutrition plan
- 📏 **BMI Calculator** — Auto-categorizes with health tips
- 🔍 **Food Explorer** — 40+ foods across 12 categories
  (grains, proteins, fruits, vegetables, dairy, chips, 
  biscuits, noodles, chocolates, drinks & more)
- ⚠️ **Allergy Detection** — Flags foods based on your 
  health profile and dietary restrictions
- 📋 **Daily Food Tracker** — Log meals, track calories
- 💧 **Water Intake Tracker** — 8 glasses daily goal
- 📈 **Analytics Dashboard** — Calories, protein, macros,
  micronutrients, water intake charts
- 🧬 **Macro & Micronutrient Tracking** — Protein, carbs,
  fat, fiber, Vitamin C, calcium, iron
- 📱 **Fully Responsive** — Works on all screen sizes

---
